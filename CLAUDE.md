# CLAUDE.md — moocai

## Branches

Name every new branch after what it changes: `claude/<short-kebab-description>` (e.g. `claude/exams-pages`, `claude/fix-navbar-stars`). Never use a random or auto-generated name. If the session hands you a generated branch name (e.g. `claude/wizardly-einstein-erqe6d`), don't develop on it: create a descriptively named branch from the same starting point and push that instead. This rule is standing permission to do so.
